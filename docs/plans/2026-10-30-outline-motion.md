## 实现约定

- 高亮背景落在标题按钮上，层级箭头/占位在高亮框外；文字左右采用相同内边距。
- 整体目录使用短淡入/淡出与小幅位移，子目录折叠使用高度过渡；快速反复操作可中断并接续当前动画。
- 退出动画结束后才隐藏节点；退出期间立即停止焦点和指针交互。保持键盘焦点与 aria-expanded/aria-controls 一致。
- 尊重 prefers-reduced-motion；不添加运行时依赖或远程脚本。
- 修复折叠时整棵树重建导致键盘焦点丢失的问题；审核结果只采纳明确的问题。
- 参考 Radix Collapsible 的高度动画与 Disclosure 语义，以及 Headless UI Transition 的进入/离开状态模型；用原生 CSS 和 Web Animations 实现。
