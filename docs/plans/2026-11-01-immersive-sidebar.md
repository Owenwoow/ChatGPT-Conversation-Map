# 沉浸模式自动收起侧边栏

- 状态：已完成
- 默认关闭；在扩展设置中提供独立开关。
- 用户补充：新聊天和历史聊天均在发送新消息并确认用户消息出现在页面后，通过网页原生按钮收起侧边栏；手动展开后，下一次发送可再次触发。
- 不在打开新聊天空页面、切换或阅读历史会话、加载更早的历史内容、失败的发送时触发。
- 页面结构证据：侧边栏按钮带 `data-app-shell-sidebar-trigger`、`aria-controls="app-shell-sidebar"` 和 `aria-expanded` 状态。
- 验证：单元测试、模拟页面回归、独立浏览器档案下的扩展测试通过；覆盖新旧聊天发送、阅读历史、加载旧消息、手动展开、无消息发送、会话切换、延迟渲染及侧栏边缘按钮。
- 真实页面验证：已读取新聊天输入区和侧边栏按钮，并检查收起与展开状态；未在真实会话发送消息。
