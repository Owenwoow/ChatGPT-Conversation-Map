# Dual Navigator V1 实现

空目录起步，无已有测试基线。原生 MV3，直接加载根目录。

1. 页面适配组：src/adapter.js、src/model.js、tests/model.test.cjs。独立 worktree；模型沿用主会话（技能中的 opus/sonnet 名称不在可用模型列表）。
2. 主会话：界面、设置、扩展清单、浏览器验证、说明和打包。
3. 集成、核心模块只读审查、单元及浏览器测试、交付。

约定接口：globalThis.DualNav = { ... }，adapter 提供 scan() → {key,main,scrollRoot,messages:[{id,role,element,text,headings:[{id,level,text,element}],streaming}],streaming}；conversation key 取路径，消息有稳定 id。adapter 另提供 getContentRect(main)、getScrollRoot(element)。model 导出 ConversationStore，其 update(snapshot) 返回 turns 数组；turn {id,user,assistant,ordinal}，消息记录保留 element（可能断开），重新出现时更新。reset(key) 清理旧会话。标题树 buildTree(headings) → 节点数组（...heading,children）。

虚拟化：只缓存本页观察过的记录，不请求私有 API；跳转未挂载消息时分步滚动恢复，超时明确提示。聊天缓存仅内存，不写网站存储或扩展存储。设置使用 chrome.storage.local。

状态：已完成。
